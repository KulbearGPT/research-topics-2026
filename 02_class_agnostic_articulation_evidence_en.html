Topic 02 · Structure Evidence

Class-agnostic Articulation Evidence Learning

Predict joint, bone, and uncertainty evidence on 3D Gaussian primitives so automatic rigging can handle objects with different structures and categories.

Input: Gaussian primitivesMiddle: joint / bone / uncertainty evidenceOutput: rigging feature map

Different objects do not share the same semantic joint names, so the model should learn which regions provide useful articulation evidence rather than fixed labels like elbow or knee.

Student Research View

Intermediate machine learning research

This topic is suitable for students who already understand baselines, training signals, and evaluation metrics. Its research contribution can focus on representation learning, label construction, and generalization.

Research question

Can different object categories share movable-structure evidence?

The project predicts regions useful for skeleton inference and skinning prediction instead of fixed semantic joint classes.

Contribution

Soft supervision + evidence learning

Construct joint distance fields, bone distance fields, or uncertainty labels from rig annotations, then test whether evidence improves downstream rigging.

Expected output

Publishable experiment loop

Label generation, evidence head, heatmap visualization, held-out category tests, downstream skeleton / skinning comparisons, and a conference-style paper.

Research Position

Core problem

General object rigging has variable topology: different objects have different joint counts, bone connections, and movable parts.

Class-agnostic evidence is more flexible than fixed semantic heatmaps for multi-category skeleton inference.

Outcome

What the project can produce

A runnable model, evidence visualizations, controlled comparisons, and a conference-style paper.

Research Path

Research path

Each stage has a concrete intermediate artifact.

Stage ATask and data

Understand skeletons, bones, skinning weights, and their relation to surface regions.

Stage BLabel construction

Generate soft distance fields or skinning transition entropy from rig annotations.

Stage CModel implementation

Implement a Gaussian feature encoder and evidence prediction head.

Stage DDownstream validation

Inject evidence into a fixed rigging baseline and compare skeleton / skinning metrics.

Stage EGeneralization analysis

Test humanoid, animal, chair, lamp, and other object forms.

Research Details

Core technical components

The method centers on evidence labels, feature learning, and downstream coupling.

Class-agnostic Evidence

Predict regions that help skeleton inference instead of fixed semantic joint names.

Soft Supervision

Use joint distance fields, bone distance fields, or skinning transition entropy as training signals.

Downstream Coupling

Validate evidence through skeleton and skinning metrics, not only visually pleasing heatmaps.
