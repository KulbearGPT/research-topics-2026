Topic 02 · Structure Evidence

类别无关 Articulation Evidence 学习

在 3D Gaussian primitives 上预测关节、骨骼和不确定性相关的结构线索，帮助自动 rigging 处理多类别对象。

输入：Gaussian primitives中间：joint / bone / uncertainty evidence输出：rigging feature map

不同物体没有统一的关节名称，因此模型不直接预测“肘部、膝盖、椅子腿”等固定语义，而是预测哪些区域对骨架推断有用。

Research Framing

研究问题设定：进阶机器学习研究

这个方向建立在 baseline、训练信号和评价指标的理解之上。它的论文味更强，因为核心贡献可以围绕表示学习、标签构建和泛化能力展开。

研究问题

不同类别对象能不能共享“可动结构线索”？

这里不需要预测固定语义关节名，而是学习哪些 Gaussian 区域对 skeleton inference 和 skinning prediction 有帮助。

论文贡献方向

Soft supervision + evidence learning

可以从 rig annotation 构建 joint distance field、bone distance field 或 uncertainty label，再验证 evidence 是否提升下游 rigging。

可能产出

实验闭环

包括 label generation、evidence head、heatmap 可视化、held-out category test、下游 skeleton / skinning 对比和 conference-style paper。

研究定位

研究问题

General object rigging 的骨架拓扑是可变的：不同物体的 joint 数量、bone 连接方式和可动部件都不一样。

固定语义 heatmap 不适合多类别对象；class-agnostic evidence 更适合作为 skeleton inference 的中间结构线索。

Research Path

阶段式研究路线

研究过程按由浅到深推进，每个阶段都对应可检查的中间产物。

Stage A任务与数据

理解 skeleton、bone、skinning weight 与 surface region 的关系。

Stage B标签构建

从 rig annotation 生成 soft distance field 或 skinning transition entropy。

Stage C模型实现

实现 Gaussian feature encoder 和 evidence prediction head。

Stage D下游验证

把 evidence 接入固定 rigging baseline，比较 skeleton / skinning 指标。

Stage E泛化分析

在 humanoid、animal、chair、lamp 等不同形态对象上观察稳定性。

Research Details

核心技术内容

技术部分围绕模型输入、监督信号、评价指标和下游验证展开。

Class-agnostic Evidence

不预测固定语义关节名，而是预测对 skeleton inference 有帮助的区域。

Soft Supervision

使用 joint distance field、bone distance field 或 skinning transition entropy 形成训练信号。

Downstream Coupling

通过 skeleton / skinning 指标验证 evidence 是否真正有用，而不只看热力图是否好看。

Evaluation

评价方式

评价指标既保留论文写作需要的专业性，也帮助学生解释“学到的 evidence 是否真的有用”。

指标 / 观察项技术含义直观解释
Evidence AUC / IoU评估 predicted evidence 与构造的 soft label 是否一致。模型标出的“关键区域”是否和我们从标注中构造出的参考区域一致。
CD-J2J预测 joint 与 GT joint 之间的 Chamfer distance。预测出来的关节点位置是否接近真实关节点。
CD-B2B预测 bone 与 GT bone 之间的几何距离。预测出来的骨骼连接是否接近真实骨架结构。
Skin L1skinning weight prediction 的误差。模型判断每个区域由哪根骨骼控制时，是否接近真实绑定权重。
Held-out Category Performance在未见类别或非 humanoid 对象上的泛化能力。方法是否只会处理训练过的类别，还是能迁移到椅子、动物、灯具等新对象。
