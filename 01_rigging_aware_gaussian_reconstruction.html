Topic 01 · Reconstruction

结构感知 Sparse-view Gaussian Reconstruction

从一张或少量图片恢复 3D Gaussian asset，并检查它是否保留后续 rigging 所需要的几何证据。

输入：1–4 张 RGB 图像中间：depth / point map / confidence输出：rigging-ready Gaussian asset

让 3D 重建结果不只在新视角下看起来相似，还能保留关节、细长结构和可动边界。

Student Research View

学生项目视角：入门推荐，但目标是论文级研究

这个方向适合作为对科研有热爱和兴趣的学生进入 3D AI 科研的起点，因为它容易产生可视化结果，同时又能提出严肃的研究问题。

研究问题

为什么“看起来像”的 3D 重建不一定适合绑定？

学生需要分析 sparse-view reconstruction 在关节、细长结构和可动边界附近的缺陷，并解释这些缺陷如何影响后续 skeleton / skinning。

论文贡献方向

Rigging-aware reconstruction 或评价

可以提出新的几何先验、confidence filtering、floater removal 或 joint-region coverage 指标，证明它们不仅改善渲染，也改善下游 rigging。

预期成果

完整 paper package

包括 baseline 复现、可控对象数据、3D viewer、定量表格、失败案例、ablation study、demo video 和 conference-style paper。

Input / Output

输入、处理结果与最终产物

该课题的对象、辅助信号、输出资产和诊断结果如下。

研究定位

研究问题

常规 reconstruction 主要优化 novel-view rendering；但 automatic rigging 需要稳定的 surface evidence，尤其是关节附近、细长结构和可动部件边界。

如果 sparse-view 重建产生 floaters、深度不一致或结构缺失，下游 skeleton prediction 和 skinning prediction 会明显受影响。

Research Path

阶段式研究路线

研究过程按由浅到深推进，每个阶段都对应可检查的中间产物。

Stage A任务与数据

跑通 sparse-view reconstruction demo，明确图像、相机、Gaussian primitive 的数据格式。

Stage B小数据实验

选择可控对象集，比较不同输入视角数量下的重建效果。

Stage C诊断指标

加入 surface coverage、floater ratio、joint-region recall 等分析。

Stage D方法改进

引入 VGGT / depth / point map / confidence filtering 等几何线索。

Stage E结果整理

汇总重建可视化、rigging-aware 诊断图和对比表。

Research Details

核心技术内容

技术部分围绕模型输入、监督信号、评价指标和下游验证展开。

Sparse-view Reconstruction

建立从 1-view / 2-view / 4-view 到 Gaussian primitives 的 baseline。

Geometry Prior

使用 depth、point map、camera confidence 等先验减少深度不一致和 floating primitives。

Rigging-aware Evaluation

把评价从“渲染像不像”扩展到“是否有助于 skeleton / skinning”。

Evaluation

评价方式

评价指标既保留论文写作需要的专业性，也给学生和家长提供直观判断方式。

指标 / 观察项技术含义直观解释
PSNR / SSIM / LPIPS传统 novel-view rendering 质量。换一个角度看 3D 结果时，图像是否清晰、相似、没有明显失真。
Chamfer DistanceGaussian centers 与真实 surface 的几何距离。重建出来的 3D 点是否贴近物体表面，而不是散在错误位置。
Floater Ratio远离表面的 noisy primitives 比例。物体周围是否出现漂浮噪点，这会影响展示和后续绑定。
Joint-region Recall关节或骨骼附近是否有足够 surface evidence。手臂、腿、椅子腿等可动区域附近是否重建完整，是否能支持骨架预测。
Downstream Skeleton Quality重建结果送入 rigging 模块后，骨架预测是否更稳定。改进后的 3D 结果是否真的让自动绑定更可靠，而不只是渲染更好看。
